# Data Folder

This repository does not include the original Excel files used for the credit card consumption analysis.

Place the following files in this folder before running the notebook:

- `CreditConsumptionData.xlsx`
- `CustomerBehaviorData.xlsx`
- `CustomerDemographics.xlsx`

These files are required to reproduce the project locally. They were originally stored in a local project directory and are intentionally not committed to GitHub.

## Expected usage
Once the files are downloaded or restored locally, run the notebook from the repository root or from the notebook folder. The notebook will look for the Excel files in the `data/` directory.

## Notes
- Do not commit private or restricted data to this repository.
- Keep dataset files out of version control using the patterns in `.gitignore`.
- If the dataset originates from a private or institutional source, document that source here before publishing.
